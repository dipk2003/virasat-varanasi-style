# 🕌 Virasat Varanasi Style — Traditional E-Commerce

A full-stack e-commerce platform for selling traditional Varanasi-style products. Features product variants, shopping cart, PDF export, and Supabase backend.

![React](https://img.shields.io/badge/React-18-61DAFB?logo=react&logoColor=black)
![TypeScript](https://img.shields.io/badge/TypeScript-blue?logo=typescript&logoColor=white)
![Supabase](https://img.shields.io/badge/Supabase-Database-green?logo=supabase&logoColor=white)

## ✨ Features
- Product Catalog with Variants
- Shopping Cart Management
- PDF Export — jsPDF for receipts/invoices
- Supabase Database and Auth
- Data Visualization with Recharts
- Dark Mode Support
- Responsive Design

## 🛠️ Tech Stack
| Technology | Purpose |
|---|---|
| React 18 + Vite | Frontend |
| TypeScript | Type safety |
| Supabase | Database and Auth |
| shadcn/ui + Radix UI | UI components |
| TanStack Query | Data fetching |
| Tailwind CSS | Styling |
| jsPDF | PDF generation |

## 🚀 Quick Start
```bash
git clone https://github.com/dipk2003/virasat-varanasi-style.git
cd virasat-varanasi-style
npm install
npm run dev
```
